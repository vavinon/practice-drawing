ยินดีต้อนรับสู่ "ห้องครัวผสมสีของพี่สาว" จ้ะ! 🍲✨  
เวลาน้องเลือกสีไม่ถูก ไม่รู้ว่าแสงจันทร์ต้องลงเงาสีอะไร หรือแสงแดดอัสดงต้องสะท้อนเข้าตาเฉดไหน น้องสามารถ "หยิบสูตรสำเร็จ (Color Recipes)" จากการ์ดเหล่านี้ไปดูดสี (Eyedropper) หรือก๊อปปี้รหัส Hex ไปใช้ในโปรแกรมวาดรูปได้ทันทีเลยจ้ะ!

## 🐺 Recipe 1: หมาป่าสีเทาเงินใต้แสงจันทร์ (Silver Wolf in Cool Moonlight)
*บรรยากาศ: ป่าสนกลางดึก คืนเดือนหงาย ลึกลับ สงบ และน่าเกรงขาม*

```
[ Light: Sky Moon ] ➔ [ Midtone: Fur ] ➔ [ Shadow: Cool Navy ] ➔ [ Rim: Cyan Silver ] ➔ [ AO: Deep Abyss ]
     #D9E8F5               #8A99AD              #323B4C                 #E0F7FA               #151922
```

- **#D9E8F5 (Highlight/Moon):** แสงจันทร์ขาวอมฟ้า ตกกระทบระนาบบนของมูเซิลและหน้าผาก
- **#8A99AD (Base Fur):** สีขนเทาเงินเนื้อแท้ (Desaturated Cool Grey)
- **#323B4C (Core Shadow):** เงาสีกรมท่าลึก (เลเยอร์ Multiply 40-50%)
- **#E0F7FA (Rim Light):** เส้นแสงสีเงินประกายเลาะตามแนวหางฟูและไรขนหลัง (โหมด Color Dodge หรือ Add)
- **#151922 (Ambient Occlusion):** ซอกหลืบมืดสนิทใต้ซอกหู ร่องฟัน และรอยพับอุ้งเท้า

## 🦊 Recipe 2: จิ้งจอกสีส้มใต้แสงแดดอัสดง (Golden Hour Autumn Fox)
*บรรยากาศ: ทุ่งหญ้าฤดูใบไม้ร่วง แสงอาทิตย์ยามเย็น อบอุ่น อาลัยอาวรณ์ โรแมนติก*

```
[ Light: Golden Sun ] ➔ [ Base: Rust Orange ] ➔ [ Shadow: Plum Violet ] ➔ [ SSS: Blood Orange ] ➔ [ Eyes: Emerald ]
      #FFD166                 #E76F51                 #4A2840                  #FF4500               #2A9D8F
```

- **#FFD166 (Key Light):** แสงแดดสีส้มทอง ส่องทำมุมเฉียงปะทะขนแผงคอด้านหน้า
- **#E76F51 (Base Fur):** สีขนจิ้งจอกสีส้มอิฐสดใส
- **#4A2840 (Cool Shadow):** **เคล็ดลับโปร!** แดดสีส้ม เงาต้องเป็นสีม่วงเปลือกมังคุด (Complementary Color)
- **#FF4500 (Subsurface Scattering):** แสงสีส้มแดงจัดทะลุผ่านขอบใบหูบางๆ
- **#2A9D8F (Accent Eyes):** สีเขียวมรกตตรงแววตา ตัดกับสีขนส้มอย่างงดงาม

## ❄️ Recipe 3: เคโมโนะขนขาวหิมะ + หูนุ่มเรืองแสง (Snow Kemono with SSS Glow)
*บรรยากาศ: ภูเขาหิมะ ท้องฟ้าครึ้มหมอก แสงนุ่มฟุ้ง สดใส บริสุทธิ์ นุ่มนิ่ม*

```
[ Base: Snow White ] ➔ [ Mid: Lavender Sky ] ➔ [ Shadow: Powder Blue ] ➔ [ Ear SSS: Rosy Peach ] ➔ [ Nose: Jelly Pink ]
       #F8FAFC                 #DDE3F0                 #A5B4CB                  #FF9EAA               #F472B6
```

- **#F8FAFC (Highlight/Base):** ขนขาวเนื้อแท้ไม่ใช่สีขาวกระดาษ แต่เป็นขาวอมฟ้าจางๆ
- **#DDE3F0 (Midtone):** เงาของขนขาวต้องเป็นสีม่วงลาเวนเดอร์อ่อนๆ
- **#A5B4CB (Shadow):** เงาตกทอดจากกรงอกลงสู่ขาหนีบ
- **#FF9EAA (Ear SSS):** แสงทะลุใบหูเป็นสีชมพูพีช ทำให้ตัวละครดูอบอุ่นและมีเลือดฝาด
- **#F472B6 (Paw/Nose):** ปุ่มเนื้อนิคุคิวและจมูกสีชมพูเยลลี่ฉ่ำวาว

## 🌆 Recipe 4: นักรบนีออนไซเบอร์พังก์ (Cyberpunk Dual-Light Warrior)
*บรรยากาศ: ซอยเมืองอนาคตฝนตก แสงป้ายไฟนีออนคู่ตรงข้าม Cyan & Magenta*

```
[ Light 1: Neon Cyan ] ➔ [ Light 2: Neon Magenta ] ➔ [ Base: Charcoal Armor ] ➔ [ Wet Bloom ] ➔ [ Visor Glow ]
       #06B6D4                  #EC4899                    #1E1E24                 #FDF4FF           #3B82F6
```

- **#06B6D4 (Key Light ซ้าย):** แสงป้ายนีออนสีฟ้าไซแอน ส่องสว่างซีกซ้ายของตัวละคร
- **#EC4899 (Rim Light ขวา):** แสงนีออนสีชมพูมาเจนต้า สาดเข้าซีกขวาตัดกันอย่างทรงพลัง
- **#1E1E24 (Body Armor):** ชุดเกราะสีเทาดำชาร์โคลเพื่อเป็นพื้นหลังรองรับแสงนีออน
- **#FDF4FF (Specular Wet):** ประกายแสงสีขาวจ้าสะท้อนบนขนเปียกฝนและขอบเกราะ
- **#3B82F6 (Visor Eye):** แว่นตาดิจิทัลเรืองแสง

## 🍺 Recipe 5: เตาผิงอบอุ่นในโรงเตี๊ยม (Cozy Fireplace Tavern Kemono)
*บรรยากาศ: ร้านอาหารคนแคระ หน้าหนาว แสงเทียนและกองไฟอบอุ่น ปลอดภัย*

```
[ Fire Core ] ➔ [ Warm Light: Amber ] ➔ [ Wood & Leather ] ➔ [ Ambient Shadow ] ➔ [ Golden Spark ]
   #FFFBEB             #F59E0B                #78350F                #291811               #FCD34D
```

- **#FFFBEB (Flame Center):** แกนกลางเปลวไฟสีขาวอมเหลืองนวล
- **#F59E0B (Key Light):** แสงไฟสีเหลืองอำพันสาดอาบใบหน้าและแก้วเบียร์ไม้
- **#78350F (Base Wood/Fur):** เสื้อกั๊กหนังและขนสีน้ำตาลอบอุ่น
- **#291811 (Deep Warm Shadow):** เงาสีน้ำตาลเข้มอมแดงในมุมมืดของห้อง
- **#FCD34D (Fire Sparks):** ละอองสะเก็ดไฟที่ลอยวนในอากาศ

## ⚔️ Recipe 6: ดาบเหล็กกล้าและขอบทองคำ (Polished Steel Blade & Gold)
*บรรยากาศ: โลหะสะท้อนโลก แดดกลางแจ้ง คมกริบ มีมิติ*

```
[ Sky Highlight ] ➔ [ Ground Reflection ] ➔ [ Steel Core ] ➔ [ Gold Trim ] ➔ [ Gold Shadow ]
     #FFFFFF                 #8D775F              #4B5563         #FBBF24          #92400E
```

- **#FFFFFF (Sharp Highlight):** เส้นสะท้อนแสงอาทิตย์สีขาวกริบบนสันคมดาบ
- **#8D775F (Ground Horizon):** โลหะเงาวับจะสะท้อนสีพื้นดินสีน้ำตาลลงบนซีกครึ่งล่างของใบดาบ
- **#4B5563 (Sky Metal):** ระนาบครึ่งบนสะท้อนสีฟ้า-เทาของท้องฟ้า
- **#FBBF24 (Gold Filigree):** ขอบโกร่งดาบสีทองคำเหลืองอร่าม
- **#92400E (Gold Shadow):** **กฎสำคัญ:** เงาของทองคำคือสีน้ำตาลไหม้ ไม่ใช่สีเหลืองเข้ม!

---

> 💡 **สูตรลัดโหมดเลเยอร์:**  
> - ลงเงา = ใช้สีจากช่อง `Shadow` บนเลเยอร์ **Multiply (Opacity 35-50%)**  
> - ลงแสงสะท้อนขอบ = ใช้สีจากช่อง `Rim Light` บนเลเยอร์ **Color Dodge หรือ Add (Glow)**
