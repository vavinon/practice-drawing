# 🔄 คลังมุมมองหมุนรอบทิศ 8 องศา (Multi-Angle Turnaround Reference Guide)

สวัสดีจ้ะน้องรัก! นักวาดหลายคนเก่งมากเวลาวาดตัวละครมุม "3/4 หันซ้าย" แต่พอต้องวาดตัวละคร "หันหลัง", "ก้มหน้ามองดิน" หรือ "แหงนหน้าคำราม" มักจะเกิดอาการตันทันที! 

คู่มือนี้ทำหน้าที่เป็น **"เข็มทิศมุมมอง 3 มิติ (The 3D Compass)"** ที่รวบรวมหลักการหมุนชิ้นส่วนยากๆ อย่าง **มูเซิล Kemono, ขาสัตว์ Digitigrade, และอุ้งมือกรงเล็บ** ให้วาดได้แม่นยำทุกองศาจ้ะ! 🧭✨

---

## 🧭 1. เข็มทิศการหมุน 8 ทิศทางหลัก (The 8-Way Rotation Compass)

```
                       [ 180° หลังตรง ]
                      ↗        |        ↖
         [ 135° หลัง 3/4 ]     |     [ 225° หลัง 3/4 ]
               ↗               |               ↖
     [ 90° ข้างซ้าย ] ─────────+───────── [ 270° ข้างขวา ]
               ↘               |               ↗
          [ 45° หน้า 3/4 ]     |     [ 315° หน้า 3/4 ]
                      ↘        |        ↙
                       [ 0° หน้าตรง ]
```

## 🐺 2. การหมุนมูเซิล Kemono ใน 5 มุมมองหลัก (Kemono Head Turnaround)

```
[ 0° หน้าตรง (Front) ]     [ 45° มุม 3/4 (Standard) ]  [ 90° ด้านข้าง (Profile) ]  [ +30° ก้มหน้า (Down) ]     [ -30° เงยหน้า (Up) ]
      ╭───∧───∧───╮              ╭───∧───∧───╮              ╭───∧───────╮              ╭───∧───∧───╮              ╭───∧───∧───╮
     │  (•)   (•)  │            │  (•)   (╭─) │            │  (•)      │            │  (•)   (•)  │            │  (•)   (•)  │
     │      ▲      │            │    ┌───▲──╯ │            │ ┌──────▲  │            │    ┌───┐    │            │     ▲     │
     │    ╰───╯    │            │    │ █ █ │  │            │ │ █ █  │  │            │    │ ▲ │ จมูก│            │   ╭───╮ คาง│
      ╰───────────╯              ╰───┴─────┴──╯             ╰─┴─────────╯            ╰───┴───┴─────╯             ╰─┴─────┴───╯
                                                                                     มูเซิลบังปากล่างมิด        เห็นใต้คาง & รูจมูก
```

### กฎเหล็กของแต่ละมุม:
1. **0° หน้าตรง (Front View):**
   - มูเซิลจะมีลักษณะเป็น "รูปตัว Y หรือสามเหลี่ยมคว่ำ" ไม่ยื่นยาวออกมานอกโครงหน้า
   - ปลายจมูกอยู่กึ่งกลางสมมาตรเป๊ะ หูสองข้างกางองศาเท่ากัน
2. **45° มุม 3/4 (Three-Quarter View - มุมยอดฮิต):**
   - **ดั้งจมูกจะตัดผ่านแก้มด้านไกล (Bridge breaks the silhouette)**
   - ตาด้านไกลแคบลงในแนวนอน (Foreshortening)
   - ปากด้านไกลสั้นกว่าปากด้านใกล้ 50%
3. **90° ด้านข้างตรง (Profile View):**
   - มองเห็น "องศาดั้งหัก (The Stop)" ระหว่างหน้าผากกับมูเซิลได้ชัดเจนที่สุด
   - สุนัขจะมีดั้งหักเป็นมุม 120° - 140° / แมวจะมีดั้งเว้าโค้งมนเล็กน้อย
   - ตาจะมองเห็นเป็นรูปทรง "สามเหลี่ยมพิซซ่า" หันไปทางซ้าย
4. **+30° ก้มหน้า (Looking Down / High Angle):**
   - **มูเซิลจะทับบดบังปากและคางเกือบมิด!**
   - เห็นระนาบด้านบนของกล่องมูเซิล (Top Plane) กว้างเป็นพิเศษ
   - ใบหูจะลู่มาชี้ด้านหน้าเล็กน้อย
5. **-30° แหงนหน้า (Looking Up / Low Angle):**
   - **มองเห็นแผ่นใต้คาง (Under-Chin Plane) และลำคอรูปทรงกระบอกชัดเจน**
   - ปลายจมูกจะลอยสูงขึ้นไปบดบังดวงตาบางส่วน
   - มองเห็นรูจมูก (Nostrils) ชัดเจน และใบหูจะลู่ไปข้างหลัง

## 🦵 3. การหมุนขาหลัง Digitigrade (Leg & Hock Turnaround)

```
[ ด้านหน้าตรง (Front) ]    [ ด้านข้าง 90° (Profile) ]  [ ด้านหลังตรง (Back) ]     [ ตอนหมอบ/งอตัว (Crouching) ]
         ╭───╮                       ╭───╮                      ╭───╮                      ╭─────────╮ สะโพก
         │   │ ต้นขาตรง              │   │ สะโพก                │   │ ก้น & รูหาง           │         │
         (   ) หัวเข่ามนุษย์         \   \ ลาดไปข้างหน้า         (   )                     \         /
         │   │ แข้งตรง                ) (  เข่า                │   │ น่องคู่               )       ( เข่าพับแนบชิด
         │   │                        \   \ ลู่ไปข้างหลัง       │   │                       \       / ส้นเท้าแนบก้น
        ( ●●● ) ข้อเท้าตรง             )   ) ข้อเท้า Hock      ( ●●● ) ส้นเท้ายกสูง         (=======) นิ้วเท้าแตะพื้น
        (====) ฝ่าเท้านิคุคิว          \   \ กระดูกฝ่าเท้า      (====) เอ็นร้อยหวายตึง
                                      (====) นิ้วเท้าแตะพื้น
```

### เคล็ดลับการจำ:
- **มองจากด้านข้าง:** จะเห็นเส้นซิกแซกตัว Z ชัดที่สุด (ทรงพลังที่สุด)
- **มองจากด้านหน้าตรง:** ขาจะดูเกือบเหมือนขามนุษย์ แต่ช่วงข้อเท้าจะคอดกิ่วและยกสูง
- **มองจากด้านหลังตรง:** จะเห็น "เส้นเอ็นร้อยหวายหนา (Achilles Tendon)" ทอดยาวลงมาหาปุ่มส้นเท้าที่ลอยอยู่กลางอากาศ

### กฎการจำสำหรับอุ้งมือ:
- **นิ้วทั้ง 4 ไม่เคยขนานกัน:** เวลาแบมือ นิ้วจะกางแผ่ออกเป็นรูปพัดเสมอ
- **ข้อต่อทรงโดม (The Metacarpal Arch):** สันข้อนิ้วเวลาหักมุมไม่ได้เป็นเส้นตรง แต่จะโค้งมนเหมือนหลังเต่า โดยข้อนิ้วกลางจะอยู่สูงที่สุดเสมอ
