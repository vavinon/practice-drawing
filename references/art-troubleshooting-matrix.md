# 🩺 คลินิกตรวจโรคงานวาด: คู่มือวินิจฉัยและแก้ปัญหาด้วยตนเอง (Art Diagnostic & Troubleshooting Matrix)

> *"เวลารู้สึกว่าภาพมีอะไรแปลกๆ แต่มองไม่ออกว่าผิดตรงไหน... ยินดีต้อนรับสู่คลินิกตรวจโรคงานวาดของพี่สาวค่ะ!"* 🩺🎨

บ่อยครั้งที่เรานั่งวาดรูปอยู่หลายชั่วโมง แต่พอมองภาพรวมกลับรู้สึก **"เอ๊ะ... มันมีอะไรผิดปกติสักอย่าง แต่บอกไม่ถูกว่าคืออะไร"**  
ตารางวินิจฉัยนี้ถูกออกแบบมาเพื่อช่วยให้น้องระบุ **"โรคของภาพ"** และมอบ **"ยาแก้เร่งด่วน"** ที่ใช้ได้ทันทีค่ะ!

---

## 🔍 ตารางเปรียบเทียบอาการและวิธีรักษา (Diagnostic Matrix)

| อาการที่ปรากฏในภาพ | สาเหตุที่แท้จริง (Diagnosis) | วิธีทดสอบ (Test) | การรักษาเร่งด่วน (Immediate Cure) |
| :--- | :--- | :--- | :--- |
| **1. หน้าเบี้ยว ตาเอียงไม่เท่ากัน** | สมองชินกับมุมมองด้านเดียว (Eye Fatigue Bias) | กดปุ่ม `Flip Canvas Horizontal` (กลับด้านภาพ) | ลากเส้นขนาน 3 เส้นเชื่อม (1) รูม่านตาสองข้าง (2) ฐานปีกจมูก (3) มุมปากสองข้าง ทุกเส้นต้องขนานกันเสมอในมุมมองปกติ |
| **2. ภาพดูแบน ไร้มิติ ไม่นูน** | ขาด Core Shadow และ Ambient Occlusion (หลืบเงาลึก) | เปลี่ยนภาพเป็นขาว-ดำ (Grayscale Check) เพื่อตรวจค่าน้ำหนัก | เติม **Ambient Occlusion (AO)** สีเข้มลึกในรอยพับ ร่องข้อพับ ใต้คาง และซอกระหว่างนิ้ว เพื่อผลักมิติให้เด้งออกมา |
| **3. สีดูหม่น ดูเป็นโคลน (Muddy Color)** | ใช้สีเทาหรือดำเกลี่ยลดความสว่างของสีเพื่อทำเงา | ตรวจสอบวงล้อสี (Color Picker) ในจุดที่เป็นเงา | ใช้เทคนิค **Hue Shifting**: เลื่อนโทนสีเงาไปยังสีข้างเคียงที่เย็นกว่าหรืออิ่มตัวขึ้น (เช่น ผิวสีส้ม -> เงาสีส้มแดง/ม่วงอ่อน ไม่ใช่สีน้ำตาลหม่น) |
| **4. ตัวละครยืนแข็งทื่อเหมือนหุ่นไม้** | ลำตัวตั้งตรง $90^\circ$ ขาด Line of Action และความสมดุล | ลากเส้นเส้นเดียวจากหัวจรดเท้า ดูว่ามีรูปทรงเป็นตัว C หรือ S หรือไม่ | ใช้กฎ **Contrapposto (สะโพกเอียงสวนทางไหล่)**: ถ้าไหล่ซ้ายยกสูง สะโพกซ้ายต้องกดต่ำ และถ่ายน้ำหนักลงขาข้างเดียว |
| **5. ภาพดูลายตา ไม่รู้จะมองตรงไหน** | คอนทราสต์ (Contrast) และรายละเอียดกระจายเท่ากันทั้งภาพ | หรี่ตาดู (Squint Test) ภาพย่อเล็กเท่าแสตมป์ | กำหนด **Focal Point** เพียงจุดเดียว! ใส่รายละเอียดและคอนทราสต์จัดสุดที่จุดนั้น ส่วนฉากหลังหรือเสื้อผ้าให้ลดทอนดีเทลลง |
| **6. ตัวละครกลืนหายไปกับฉากหลัง** | ค่า Value ของตัวละครกับฉากหลังเท่ากันเกินไป | ใส่เลเยอร์สีดำล้วนด้านบนสุด แล้วเปลี่ยนโหมดเป็น `Color` เพื่อดู Value | แยก Value 3 ระยะ: ฉากหลังสว่าง/หมอกคลุม (High-key) $\rightarrow$ ตัวละครค่าน้ำหนักชัดเจน $\rightarrow$ หรือใส่ **Rim Light (แสงขอบ)** รอบตัวละคร |
| **7. นิ้วมือดูเหมือนหวีกล้วย ไร้กระดูก** | วาดนิ้วเป็นเส้นขนานเดี่ยวๆ โดยไม่ขึ้นกล่องฝ่ามือ | ตรวจสอบแนวข้อนิ้ว (Knuckle Arch) | วาด **"กล่องฝ่ามือสี่เหลี่ยมคางหมู"** ก่อนเสมอ แล้วลากเส้นโค้งโดมกำหนดตำแหน่งข้อนิ้ว ก่อนจะใส่ท่อนนิ้ว 3 ปล้อง |
| **8. เส้นสายสั่น ไม่คม ไร้ความมั่นใจ** | ใช้ข้อมือลากเส้นสั้นๆ ย้ำต่อกัน (Hairy Lines) | สังเกตการเคลื่อนไหวของแขนขณะลากเส้น | ปลดปล่อยข้อต่อ! ลากเส้นด้วย **"ข้อศอกและหัวไหล่"** ใช้เทคนิค Ghosting ลอยมือก่อน แล้วตวัดเส้นยาวในจังหวะเดียว |
| **9. สรีระ Kemono ขาดูแปลกเหมือนหัก** | สับสนตำแหน่งข้อเท้า (Hock) คิดว่าเป็นหัวเข่า | เทียบมุมกระดูกขากับ S-Curve Flow | ตรวจสอบว่ามีกระดูก 3 ท่อนชัดเจน: ต้นขาเอียงหน้า $\rightarrow$ หน้าแข้งเอียงหลัง $\rightarrow$ ส้นเท้ายกสูงกลางอากาศ (ไม่ใช่ติดพื้น) |
| **10. รอยยับผ้าดูเหมือนเส้นบะหมี่** | ลากเส้นย่นมั่วๆ โดยไม่มองหาจุดดึงรั้ง (Tension Points) | มองหาจุดที่ผ้ายึดติดกับร่างกาย (เช่น ไหล่ ศอก เอว) | รอยยับทุกเส้นต้อง **"พุ่งออกจากจุดตรึง (Anchor Point)"** ตามแรงดึงดูดโลกเสมอ |

## 🛠️ ขั้นตอน 4 Step ตรวจสุขภาพงานวาดประจำวัน (Pre-Export Checklist)

ก่อนกดเซฟภาพหรือส่งงาน ให้ทำ 4 ขั้นตอนนี้เป็นกิจวัตรเสมอจ้ะ:

1. 🔄 **Flip Canvas (กลับด้านภาพ)**: เพื่อรีเซ็ตสมอง ตรวจสอบความสมดุล ซ้าย-ขวา ทันที
2. 👁️ **Squint Test / Grayscale Check (หรี่ตามองภาพขาว-ดำ)**: ย่อภาพให้เล็ก หรี่ตาดูว่า "จุดเด่น (Focal Point)" ยังเตะตาชัดเจนอยู่ไหม? หรือกลืนไปกับฉาก?
3. ⬛ **Silhouette Check (ตรวจเงาดำ)**: ถมตัวละครเป็นสีดำล้วน 1 เลเยอร์ แล้วดูว่า "อ่านท่าทาง อาวุธ และรูปทรงออกทันทีหรือไม่?" ถ้าดูไม่ออก ให้ปรับแขนขาไม่ให้แนบลำตัวเกินไป
4. 🌈 **Histogram / Curves Polish (จูนคอนทราสต์สุดท้าย)**: ตรวจดูว่าภาพมีทั้งส่วนที่สว่างที่สุด (Near-White) และส่วนที่มืดที่สุด (Near-Black) ครบถ้วน ไม่เทาจืดทั้งภาพ
