# 💻 คู่มือเทคนิคดิจิทัล: เลเยอร์ โหมดผสมสี และประเภทบรัช (Digital Workflow Guide)

ยินดีต้อนรับสู่คู่มือเทคนิคการวาดภาพดิจิทัลฉบับสมบูรณ์ค่ะ! 🎨✨ ไม่ว่าน้องจะใช้โปรแกรม **Clip Studio Paint, Photoshop, Procreate, หรือ IbisPaint** หลักการทำงานของเลเยอร์ โหมดผสมสี (Blending Modes) และหัวแปรง (Brushes) ใช้มาตรฐานชุดเดียวกันทั่วโลกค่ะ!

---

## 📑 1. ลำดับเลเยอร์มาตรฐานสากล (Standard Layer Hierarchy)

หนึ่งในข้อผิดพลาดที่ใหญ่ที่สุดของมือใหม่ คือการ **"วาดและลงสีทุกอย่างในเลเยอร์เดียว"** ทำให้เวลาจะแก้ไขเงาหรือเส้นร่าง ต้องลบใหม่ทั้งหมด! ให้จัดลำดับเลเยอร์จากบนลงล่างดังนี้:

```
[ ด้านบนสุด ]
▲ เลเยอร์ 6: เอฟเฟกต์แสงและบรรยากาศ (Bloom / Fog / Particles) [Add Glow / Overlay]
▲ เลเยอร์ 5: เส้นตัดเส้นสะอาด (Lineart) [Normal]
▲ เลเยอร์ 4: แสงไฮไลต์ & Rim Light (Clipping Mask ทับสีพื้น) [Screen / Add Glow]
▲ เลเยอร์ 3: เงาและมิติ (Clipping Mask ทับสีพื้น) [Multiply]
▲ เลเยอร์ 2: สีพื้นเรียบไม่มีเงา (Flat / Base Colors) [Normal]
▲ เลเยอร์ 1: เส้นร่างหยาบ (Rough Sketch) [ปรับ Opacity เหลือ 20-30%]
▲ เลเยอร์ 0: ฉากหลัง (Background) [Normal]
[ ด้านล่างสุด ]
```

## 🔒 2. พลังวิเศษของ "Clipping Mask" และ "Alpha Lock"

### 1) Clipping Mask (หน้ากากตัดขอบ) — ⭐ สำคัญที่สุด!
- **วิธีใช้**: สร้างเลเยอร์เงาขึ้นมาเหนือเลเยอร์สีพื้น แล้วกดปุ่ม **"Clipping Mask"**
- **ผลลัพธ์**: ไม่ว่าน้องจะปาดพู่กันสะบัดกว้างแค่ไหน **สีจะไม่มีวันล้นออกนอกขอบของตัวละครเลยแม้แต่มิลลิเมตรเดียว!** น้องสามารถระบายเงาได้อย่างรวดเร็วและมั่นใจ

### 2) Alpha Lock (ล็อคความโปร่งใส)
- **วิธีใช้**: กดล็อคเลเยอร์ที่มีเนื้อสีอยู่แล้ว
- **ผลลัพธ์**: จะระบายสีทับได้เฉพาะบนเนื้อสีเดิม เหมาะมากสำหรับ **"การเปลี่ยนสีเส้นตัดเส้น (Coloring Lineart)"** เช่น เปลี่ยนเส้นขนจากสีดำเป็นสีน้ำตาลอ่อนตามสีขน

## 🌓 3. 4 โหมดผสมสียอดนิยม (Essential Blending Modes)

| โหมดเลเยอร์ | การทำงาน | การนำไปใช้ในงานวาด |
| :--- | :--- | :--- |
| **Normal** (ปกติ) | วางทับสีเดิมตรงๆ แบบทึบแสง | ลงสีพื้น (Base Color), ตัดเส้น (Lineart) |
| **Multiply** (คูณ) | นำค่าความมืดมาคูณกัน ทำให้สีเข้มขึ้น โดยยังคงรักษาความสดของสีเดิมไว้ | **ใช้ทำเงาทั้งหมด!** (เงาช่อขน, Cast Shadow, Core Shadow) |
| **Screen / Add (Glow)** | นำค่าความสว่างมารวมกัน ทำให้สีสว่างวาบและเรืองแสง | ไฮไลต์ประกายตา, แสงเวทมนตร์, แสงแดด Rim Light, แสงเทียนในตะเกียง |
| **Overlay / Soft Light** | เพิ่มคอนทราสต์ สีสว่างจะสว่างขึ้น สีมืดจะมืดลง | ปรับอุณหภูมิแสงทั้งภาพ เช่น ย้อมภาพให้เป็นโทนส้มยามเย็น |

## 🖌️ 4. 3 ประเภทหัวแปรงที่นักวาดทุกคนต้องมี (The 3 Essential Brushes)

1. **Hard Round / G-Pen (บรัชหัวแข็งคมกริบ)**:
   - **ลักษณะ**: ขอบคมกริบ ควบคุมเส้นและน้ำหนักแรงกด (Pen Pressure) ได้แม่นยำ
   - **การใช้งาน**: ตัดเส้น (Lineart), กั้นเงาตกทอด (Cast Shadow), วาดปลายกรงเล็บและเส้นผม/ขนช่อคม
2. **Soft Airbrush (แอร์บรัชฟุ้งนุ่ม)**:
   - **ลักษณะ**: ขอบเบลอ ไล่เฉดสีนุ่มนวลเหมือนควัน
   - **การใช้งาน**: เกลี่ยเงามนบนแก้ม (Form Shadow), ไล่สีท้องฟ้า, ทำแสงเรืองรอง SSS ขอบหู
3. **Flat / Textured Chalk Brush (พู่กันเนื้อสัมผัส/ชอล์ก)**:
   - **ลักษณะ**: มีรอยเกรนและริ้วพู่กันคล้ายสีน้ำมันหรือสีอะคริลิก
   - **การใช้งาน**: ระบายช่อขนสัตว์ (Fur Clumps), ลายเปลือกไม้, โขดหินผา, และใบไม้

## 📐 5. การตั้งค่าหน้ากระดาษ (Canvas Setup)

- **ความละเอียดมาตรฐาน**: สำหรับงานวาดทั่วไป แนะนำ **2000 x 2000 px** ขึ้นไป หรือขนาด **A4 (2894 x 4093 px)**
- **DPI (ความคมชัด)**: ตั้งค่าที่ **300 DPI** เสมอ (เพื่อรองรับการซูมและพิมพ์ลงกระดาษไม่แตก)
- **Color Mode**: ตั้งเป็น **RGB** สำหรับแสดงผลบนจอมือถือและอินเทอร์เน็ต
