# 🪜 แผ่นภาพสตริปโครงสร้าง 4 จังหวะ (Step-by-Step Construction Strips)

แผ่นภาพนำทางลำดับการวาดจาก "ศูนย์สู่ภาพสมบูรณ์แบบ" เพื่อให้น้องรู้ชัดเจนว่า **ในแต่ละวินาทีของการวาด มือและสายตาควรโฟกัสอะไร** ไม่หลงทาง และไม่เผลอลงดีเทลก่อนวางโครงสร้างจ้ะ! ✨

---

## 🐺 Strip 1: การวาดตัวละคร Kemono เต็มตัว (Full-Body Kemono Character)

```
[ Step 1: Gesture & Energy ]    [ Step 2: 3D Mannequin ]      [ Step 3: Anatomy & Line ]    [ Step 4: Value & Lighting ]
       (5 นาทีแรก)                   (15 นาทีถัดมา)                 (25 นาทีถัดมา)                 (15 นาทีสุดท้าย)
          ( ) ศีรษะ                      ╭───╮ กะโหลกทรงกลม            ╭───╮ หูตั้งขนฟู              ╭───╮ Rim Light
         /                              │   │ + มูเซิลกล่อง          │ 🦊 │ ตาเฉียงมุ่งมั่น          │ ✨ │ แสงขอบขับเน้น
        (  Line of Action              ╭┴───┴╮ กรงอกกล่องเอียง        ╭┴───┴╮ เสื้อเกราะอก          ╭┴───┴╮ แสงอุ่นส่องหน้า
         \ กระดูกสันหลัง               │     │                       │ 🛡️  │ + ช่อขนคอริบบิ้น        │     │ เงาเย็นม่วง
          )                            ╰┬───┬╯ เชิงกรานเอียงสวนทาง     ╰┬───┬╯ เข็มขัด & ช่องหาง     ╰┬───┬╯
         /                              │   │                         │   │                         │   │

```

### รายละเอียดแต่ละสเต็ป:
1. **Step 1 (Gesture):** ลากเส้นแกนพลัง 1 เส้น + วางตำแหน่งวงกลมหัว และเท้าที่รับน้ำหนัก *ห้ามวาดตา ห้ามวาดนิ้ว!*
2. **Step 2 (Mannequinization):** ครอบด้วยกล่องกรงอกและเชิงกรานแบบ Contrapposto (เอียงสวนทางกัน) + ขาสปริงตัว Z
3. **Step 3 (Anatomy & Line Art):** หรี่ Opacity เลเยอร์หุ่นลง ใส่กล้ามเนื้อ หู ตา จมูกปาก ช่อขน ตัดเส้นด้วยน้ำหนักเส้น (Line Weight)
4. **Step 4 (Value & Light):** ลงสีพื้น + สาดแสงหลัก Key Light (45°) + เงา Multiply + ขลิบ Rim Light สีทองเลาะตามแนวขน

## 🐾 Strip 2: การวาดศีรษะและมูเซิล Kemono (Kemono Head & Snout)

```

          ╭─────╮                        ╭─────╮                       ╭─────╮ หูสัตว์สื่ออารมณ์      ╭─────╮ ไฮไลต์แววตา

         │───┼───│ แนวระดับสายตา        ├───┼───┤ โคนมูเซิล           │ (•) (•)│ ตากลมโต              │ (•) (•)│ SSS ทะลุหู
         │   │   │                      │  ┌┴─┐ │ กล่องปากจมูก        │  ╰─┬─╯ │ ช่อขนแก้มริบบิ้น      │  ╰─█─╯ │ เงาใต้คาง AO
          ╰─────╯                        ╰─┴───┴╯ ยื่นออกมา 3D         ╰───────╯                       ╰───────╯
```

### รายละเอียดแต่ละสเต็ป:
1. **Step 1 (ทรงกลมและแกนหน้า):** วาดลูกบอลกะโหลก แล้วผ่าเส้นศูนย์สูตร (Eyeline) และเส้นกึ่งกลางใบหน้า (Centerline)
2. **Step 2 (กล่องมูเซิล 3D):** ต่อกล่องสี่เหลี่ยมคางหมูยื่นออกมาจากจุดตัดของแกนหน้า โดยกำหนดให้ปลายกล่องลู่เข้าหาเปอร์สเปกทีฟ
3. **Step 3 (เครื่องหน้าและช่อขน):** วางเบ้าตาโอบรอบขอบกล่องมูเซิล เติมจมูกสามเหลี่ยม วางฐานหูรูปกรวย และเติมช่อขนแก้มทรงริบบิ้น
4. **Step 4 (แสงเงาและมิติ):** ระบายแสงเงาตามระนาบกล่อง (บนสว่าง ข้างมืด ล่างมืดสุด) เติมสีชมพูส้มเรืองแสง (SSS) ที่ใบหู

## 🦵 Strip 3: การวาดขาหลัง Digitigrade (Digitigrade Leg Breakdown)

```
[ Step 1: Bone Stick Rhythm ]   [ Step 2: Cylinders & Hock ]  [ Step 3: Muscular Flow ]     [ Step 4: Fur & Paw Pads ]
            O สะโพก                        ( ) สะโพก                     ╭───╮ กล้ามต้นขาหนา           ╭───╮ ช่อขนสะโพกฟู
           /                              /   / ทรงกระบอกต้นขา           │   │                         │   │
          O เข่าแท้จริง (Stifle)         ( ) ( ) เข่าทรงกลม             ╰─╮ ╰─╮ กล้ามแข้ง Gastro       ╰─╮ ╰─╮
           \                              \   \ ทรงกระบอกแข้ง             \   \                        \   \
            O ข้อเท้า (Hock)               ( )  ข้อเท้าลอยสูง              )   ) เอ็นร้อยหวายตึง         )   )

```

### รายละเอียดแต่ละสเต็ป:
1. **Step 1 (ก้านกระดูกรูปตัว Z):** วาดจุดหมุนข้อต่อ 4 จุด: สะโพก ➔ เข่า ➔ ส้นเท้า (ลอยกลางอากาศ) ➔ นิ้วเท้า
2. **Step 2 (ทรงกระบอกเนื้อ):** เชื่อมข้อต่อด้วยทรงกระบอก 3 ท่อน เพื่อกำหนดปริมาตรความหนา
3. **Step 3 (กล้ามเนื้อและเอ็น):** ใส่กล้ามเนื้อต้นขาด้านหน้า (Quads), กล้ามเนื้อน่อง (Gastrocnemius), และเส้นเอ็นร้อยหวายที่ตึงเปรี๊ยะ
4. **Step 4 (ขนและอุ้งเท้านิคุคิว):** วาดช่อขนปกคลุมตามทิศทางการงอก เติมปุ่มเนื้ออุ้งเท้า (Paw Pads) ที่บี้แบนสัมผัสพื้นเล็กน้อย

### รายละเอียดแต่ละสเต็ป:
1. **Step 1 (กล่องแกนสมมาตร):** ลากเส้นกึ่งกลางดาบ แล้วตีกล่องสี่เหลี่ยม 3 มิติครอบ เพื่อควบคุมไม่ให้ใบดาบบิดเบี้ยว
2. **Step 2 (การบากระนาบ Beveling):** ตัดมุมกล่องให้เกิด "สันแกนกลาง (Ridge Line)" แบ่งใบดาบออกเป็นระนาบรับแสงและระนาบมืด
3. **Step 3 (ลวดลายและอักขระ):** วาดลายพันผ้าหนังที่ด้ามจับ โกร่งดาบ และสลักอักขระเวทมนตร์บนตัวดาบ
4. **Step 4 (เรนเดอร์โลหะ):** ใส่แถบสะท้อนแสงท้องฟ้า (Sky Reflection) และเส้นไฮไลต์สีขาวคมกริบบนสันคมดาบ

### รายละเอียดแต่ละสเต็ป:
1. **Step 1 (จังหวะลำต้น):** ลากเส้นกิ่งก้านเป็นเส้นสายพริ้วไหวที่หยั่งรากลงดินอย่างมั่นคง
2. **Step 2 (ลูกบอลพุ่มใบ):** อย่าเพิ่งวาดใบไม้เดี่ยวๆ! ให้มองพุ่มไม้เป็น **"ลูกบอลเมฆก้อนใหญ่ 3-4 ลูก"** ซ้อนกัน
3. **Step 3 (ช่อใบไม้ริบบิ้น):** วาดรอยหยักของใบไม้เฉพาะตรงขอบของลูกบอลพุ่มไม้
4. **Step 4 (แสงลอด Komorebi):** กำหนดแสงแดดส่องจากด้านบน ระบายเงาใต้พุ่มบอลแต่ละลูก แล้วเจาะรูแสงสีทองลอดผ่านแมกไม้ลงสู่พื้น
